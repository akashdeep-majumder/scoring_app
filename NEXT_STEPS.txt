STEP 1: Create GitHub Repository
   → Go to: https://github.com/new
   → Repository name: cricket-scoring-app
   → Visibility: Public or Private
   → DO NOT initialize with README
   → Click "Create repository"

STEP 2: Push Your Code
   → Copy your repository URL from GitHub
   → Run these commands:

   git remote add origin https://github.com/YOUR_USERNAME/cricket-scoring-app.git
   git push -u origin master

STEP 3: Watch Builds
   → Go to: https://github.com/YOUR_USERNAME/cricket-scoring-app/actions
   → Watch the build process (takes ~10 minutes)
   → Download installers from "Artifacts" section

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Build Failed?
   → Click on failed workflow in Actions tab
   → Read error logs
   → Most common: Check package.json syntax

Can't Push?
   → Verify remote URL: git remote -v
   → Try: git pull origin master --rebase

No Artifacts?
   → Ensure build completed successfully (green checkmark)
   → Check "Artifacts" section at bottom of workflow run
